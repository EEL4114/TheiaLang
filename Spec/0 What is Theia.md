# Programming Language Ideas

## Goals
* High expressiveness
* Human- and Compiler-understandable code
* Manual and GC memory management
* Good performance
* Low-friction coding
* simplicity
* low bug-risk

## Other Notes
* no classic OOP
* no exceptions
* C-like syntax
* strongly, statically typed
* Easy refactoring
* Permissive by default, restrictive by choice
* Compact, consistent syntax
* strong compiler enforcements
* plenty compile-time functionality
* good compile times
* terse but readable (ideally english-like)
* pleasant to use
* Close, compact compile-time test integration
